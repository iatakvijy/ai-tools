# Инструменты, которые я собрал с Claude Code

Небольшие рабочие скрипты из моей личной AI-системы. Код написан вместе с Claude Code, задачи, проверка и доводка до рабочего состояния - мои.

## shorts-outliers - почему ролик залетел

Сравнивает не хиты разных авторов, а **хит и провал одного автора**: тот же человек, камера и канал, значит, разница в самом ролике (тема, крючок, формат). Правило ниши - то, что повторяется в парах у многих каналов.

```
pip install yt-dlp
python shorts-outliers/scan.py мой-прогон "запрос 1" "запрос 2"
```

Для каждого канала берёт последние 60 Shorts, считает медиану просмотров, находит выбросы (≥ 5× медианы) и контрольный ролик того же канала по соседству во времени. На выходе `каналы.csv`, `ролики.csv`, `пары.csv` и `отчёт.md` с первыми секундами речи из автосубтитров. 40 каналов - около 10-15 минут (паузы между запросами, чтобы не ловить 429).

## tg-jobs - вакансии из открытых Telegram-каналов

Читает публичные превью каналов (`t.me/s/<канал>`, без авторизации) за N дней и оставляет посты по ключевым словам, отсекая по стоп-словам.

```
python tg-jobs/tg_jobs.py канал1,канал2 7
```

Фильтры - два регулярных выражения в начале файла (`KW` и `BAD`), их легко подстроить под свою задачу. Результат - `tg_jobs_out.json`.
